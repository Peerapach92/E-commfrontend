# รูปและไฟล์เสียงที่ต้องใส่เอง

ทุกไฟล์ในโฟลเดอร์นี้เป็น **ของเสริม** — ไฟล์ไหนไม่มี เว็บจะถอยไปใช้พื้นหลัง/เสียงเริ่มต้น
แทนโดยอัตโนมัติ ไม่มีรูปแตก ไม่มี error

Vite เสิร์ฟโฟลเดอร์ `public/` ที่ root ดังนั้น `public/assets/menus/red/shop.jpg`
จะถูกเรียกด้วย path `/assets/menus/red/shop.jpg`

---

## 0. ระบบสลับธีม — น้ำเงิน (P3) ↔ แดง-ดำ (P5)

เว็บนี้มี **ปุ่มสลับธีม** อยู่มุมซ้ายบน (ข้าง ๆ ป้าย "SIGNED IN AS ...") กดแล้ว
สีทั้งเว็บ ฟอนต์ รูปพื้นหลัง และเพลง จะเปลี่ยนพร้อมกันทั้งหมด ผ่านม่านตัดฉากเดิม
(component: `src/theme/theme.js`, ปุ่มอยู่ใน `src/theme/Hud.jsx`)

เพราะแบบนี้ รูปพื้นหลังและเพลงต้อง **มีสองชุด** — ชุดละธีม ไฟล์ที่ต้องมีต่อธีมคือ:

| | ธีมน้ำเงิน (ค่าเริ่มต้น) | ธีมแดง-ดำ |
|---|---|---|
| รูปพื้นหลัง | `menus/blue/<screen>.jpg` | `menus/red/<screen>.jpg` |
| เพลง | `sfx/bgm-blue.mp3` | `sfx/bgm-red.mp3` |

ธีมสีเลือกจำไว้ใน localStorage เข้าเว็บรอบหน้าธีมเดิมยังอยู่ ไม่ต้องกดใหม่ทุกครั้ง

---

## 1. รูปพื้นหลังต่อหน้าจอ — `public/assets/menus/<ธีม>/`

นี่คือส่วนที่ทำให้หน้าตาเหมือนในคลิปมากที่สุด แต่ละหน้าจอมีรูปของตัวเอง
สลับหน้าแล้วรูปจะ fade เปลี่ยนตาม และสลับธีมแล้วก็จะเปลี่ยนไปใช้รูปอีกโฟลเดอร์ทันที

> ⚠️ **ชื่อไฟล์ต้องตรงเป๊ะ** — ตัวพิมพ์เล็กทั้งหมด ไม่มีคำอื่นปนมา ไม่มีจุดเกิน
> ตัวอย่างที่ **ผิด** ที่เจอบ่อย: `login..jpg` (จุดสองจุด), `login .jpg` (มีช่องว่าง)
>
> Windows ซ่อนนามสกุลไฟล์ที่รู้จักอยู่แล้ว (`.jpg`, `.png` ฯลฯ) เวลาเปลี่ยนชื่อไฟล์
> ให้พิมพ์แค่ชื่อ เช่น `login` แล้วกด Enter — **ไม่ต้องพิมพ์ `.jpg` เพิ่มเอง**
> ถ้า Explorer โชว์ชื่อไฟล์มีจุดต่อท้าย (เช่น "login.") แปลว่าไฟล์จริงชื่อ `login..jpg`
> ผิดแล้ว ให้เปลี่ยนชื่อใหม่
>
> ถ้าหา `.jpg` ไม่เจอ โค้ดจะลองหา `.jpeg` → `.png` → `.webp` ให้อัตโนมัติ

| ไฟล์ (ในแต่ละโฟลเดอร์ธีม) | ใช้ตอนไหน | แนะนำ |
|---|---|---|
| `login.jpg` | หน้าเข้าสู่ระบบ | ภาพเดียวที่ผู้ใช้เห็นก่อนล็อกอิน — ควรเป็นภาพ "ปก" ที่สวยที่สุด |
| `shop.jpg` | หน้ารายการสินค้า | คนอยู่หน้านี้นานสุด ใช้ภาพที่ไม่ลายตา ตัวละครควรอยู่ **ฝั่งขวา** |
| `checkout.jpg` | หน้าชำระเงิน | โทนเข้มกว่าหน้าอื่นหน่อยจะช่วยให้ฟอร์มอ่านง่าย |
| `confirmation.jpg` | หน้ายืนยันคำสั่งซื้อ | ภาพโทนสว่าง/ฉลอง |

**สถานะตอนนี้:**

- **`menus/red/`** — ใส่รูปจากไฟล์ portfolio P5 ของคุณให้แล้ว (แปลงชื่อ/ใช้เป็น
  placeholder ไปก่อน): `home.jpg → login.jpg`, `skills.jpg → shop.jpg`,
  `about.jpg → checkout.jpg`, `contact.jpg → confirmation.jpg` — ถ้าอยากได้รูปที่
  ตรงกับหน้าร้านจริง ๆ มากกว่านี้ เปลี่ยนทับได้เลย
- **`menus/blue/`** — ว่างอยู่ (มีแต่ `.gitkeep`) เพราะรูปที่คุณเคยส่งมาก่อนหน้านี้
  (login/shop/checkout/confirmation) อยู่ในเครื่องคุณเอง ผมไม่มีไฟล์นั้น —
  **ย้ายรูปเดิมของคุณมาไว้ในโฟลเดอร์ `menus/blue/` นี้** (ชื่อไฟล์เหมือนเดิม)
  ธีมน้ำเงินจะกลับมาเห็นรูปเหมือนก่อนหน้า

**สเปกที่แนะนำ**

- ขนาด 1920×1080 ขึ้นไป (ภาพถูก `object-fit: cover` เต็มจอ)
- `.jpg` คุณภาพ ~80 ไฟล์ไม่ควรเกิน 400 KB ต่อใบ ไม่งั้นโหลดช้า
- เนื้อหาสำคัญ (หน้าตัวละคร) วางไว้ **ฝั่งขวาของภาพ** เพราะฝั่งซ้ายจะถูกข้อความทับ

**ถ้าอยากเพิ่มหน้าจอใหม่** เพิ่มชื่อในอาร์เรย์ `SCREENS` ที่หัวไฟล์ `src/theme/Backdrop.jsx`
(ใช้ชื่อเดียวกันทั้งสองโฟลเดอร์ธีม)

## 2. เพลงพื้นหลัง (BGM) — `public/assets/sfx/bgm-blue.mp3` และ `bgm-red.mp3`

**พฤติกรรม:** เล่นตั้งแต่คลิก/กดคีย์บอร์ดครั้งแรกในเว็บ แล้ว **วนลูปต่อเนื่องไปเรื่อย ๆ
ไม่รีสตาร์ทตอนกดปุ่ม และเล่นข้ามหน้าต่อเนื่อง** — สลับหน้าไปหน้าไหนก็ยังฟังต่อจาก
ตำแหน่งเดิม แต่ถ้า **สลับธีม** เพลงจะเปลี่ยนไปเล่นอีกไฟล์หนึ่งแทน (ตั้งใจให้รีสตาร์ท
เพราะเป็นคนละเพลงกัน)

**สถานะตอนนี้:**

- **`bgm-blue.mp3`** — มีอยู่แล้ว (เพลงที่คุณอัปโหลดมาให้ก่อนหน้านี้)
- **`bgm-red.mp3`** — **ยังไม่มีไฟล์** เพราะไฟล์ P5 ที่ส่งมามีแค่เสียงคลิกสั้น ๆ
  0.77 วินาที (`assets/sfx/select.mp3` ในซิปนั้น) ไม่ใช่เพลงเต็ม ผมเลยไม่เอามาใส่
  หลอก ๆ เป็นเพลงพื้นหลัง เพราะจะวนซ้ำสั้น ๆ ฟังแล้วน่าจะรำคาญกว่าดี — **อัปโหลด
  เพลงสำหรับธีมแดงมาได้เลยเหมือนตอนที่ส่งเพลงน้ำเงินมา** แล้วผมจะใส่ให้เป็นไฟล์นี้
  ระหว่างนี้ถ้ากดสลับไปธีมแดง เพลงจะแค่เงียบไปเฉย ๆ (ไม่ error ไม่พัง)

- อยากเปลี่ยนเพลง: เขียนทับไฟล์ที่เกี่ยวข้องด้วย `.mp3` ของตัวเอง (เพลงยาวได้ตามใจ
  เพราะเล่นวนลูป)
- อยากแก้ความดังสูงสุด: `src/theme/sfx.js` บรรทัด `const MAX_GAIN = 0.45;`
- เบราว์เซอร์บล็อกเสียงจนกว่าจะมี user gesture ครั้งแรก — เป็นข้อจำกัดของเบราว์เซอร์เอง
  **คลิกแรกเพลงจะยังไม่ขึ้น แต่จากคลิกที่สองเป็นต้นไปเพลงจะเล่นต่อเนื่องยาวไปตลอด**
- ผู้ใช้ปรับเสียงได้จากแถบเลื่อน/ปุ่ม −/+/ลำโพงมุมขวาล่าง ค่าถูกจำไว้ใน localStorage

## 3. เสียง hover — `public/assets/sfx/hover.mp3`

ไฟล์นี้ **ใส่มาให้แล้ว** เล่นทุกครั้งที่เอาเมาส์ไปวางบนปุ่ม/ลิงก์/การ์ดสินค้าอะไรก็ตาม
ทั่วทั้งเว็บ **ใช้เสียงเดียวกันทั้งสองธีม** (ไม่ได้แยกไฟล์ตามธีม เพราะเสียงสั้นมาก
ไม่ค่อยรู้สึกถึงความต่าง) — ถ้าอยากแยกเสียง hover ตามธีมด้วย บอกได้ทำเพิ่มให้

- อยากเปลี่ยนเสียง: เขียนทับไฟล์นี้ด้วย `.mp3` ของตัวเอง (แนะนำสั้น ๆ ไม่เกิน 1 วินาที)
- อยากแก้ความดัง: `src/theme/hoverSfx.js` บรรทัด `const MAX_GAIN = 0.35;`
- ใช้ระดับเสียงเดียวกับเพลงพื้นหลัง ปิดเสียงเป็น 0% แล้ว hover จะไม่มีเสียงไปด้วย
- เล่นเฉพาะเครื่องที่มีเมาส์จริง ไม่เล่นตอนแตะจอมือถือ

## 4. ของที่ยังว่างอยู่ (ใส่หรือไม่ใส่ก็ได้)

| ไฟล์ | ผล |
|---|---|
| `favicon.ico` หรือ `favicon.svg` ที่ `public/` | ไอคอนบนแท็บเบราว์เซอร์ — ตอนนี้ยังเป็นค่าเริ่มต้น ต้องเพิ่ม `<link rel="icon">` ใน `index.html` เอง |
| รูปสินค้า | **ไม่ได้อยู่ในโฟลเดอร์นี้** — มาจากฟิลด์ `image_url` ในฐานข้อมูล (`db/init.sql`) ไม่ใช่ไฟล์ในโปรเจกต์ |

## สรุปสั้น ๆ: สิ่งที่ควรทำต่อ

1. ย้ายรูปพื้นหลังธีมน้ำเงินเดิมของคุณเข้าไปที่ `menus/blue/`
2. อัปโหลดเพลงสำหรับธีมแดงมาให้ผมใส่เป็น `sfx/bgm-red.mp3`
3. (ไม่บังคับ) เปลี่ยนรูป `menus/red/*.jpg` เป็นรูปที่ตรงกับหน้าร้านจริงมากกว่า placeholder จาก portfolio
